# VooDoo — простой и мощный трекер задач

**VooDoo** — это Android-приложение для управления задачами с поддержкой иерархии, таймеров, календаря, контекстов и полного резервного копирования через CSV.

---

## Основные возможности

### Управление задачами
- **Иерархическая структура**: неограниченная вложенность подзадач
- **Контексты**: группировка задач по проектам с настраиваемыми цветами
- **Приоритеты**: 4 уровня приоритета для сортировки работы
- **Рутина**: выделенный режим для повторяющихся задач
- **Drag-and-Drop**: перестановка задач простым перетаскиванием
- **Свайп-меню**: быстрые действия по свайпу (удалить, завершить, переместить)

### Таймер и сессии
- **Таймер задач**: отслеживание времени работы с задачей
- **Сессии**: полная история таймерных сессий с комментариями
- **Фоновый режим**: таймер работает через Foreground Service
- **Итоговая статистика**: суммарное время по каждой задаче

### Календарь
- **Временная шкала**: отображение задач и сессий на календаре
- **Планирование**: настройка дат начала и конца задач
- **Напоминания**: автоматические уведомления перед дедлайном
- **Фильтрация по контекстам**: выбор контекстов для отображения в календаре

### Экспорт, импорт и интеграции
- **Экспорт в CSV**: полная выгрузка всех данных (контексты, иерархия задач, сессии таймера с комментариями) в единый файл
- **Импорт из CSV**: безопасное восстановление из бэкапа с сохранением иерархии, связей и комментариев
- **Защита от потери данных**: база данных обновляется только после успешного парсинга файла, в одной атомарной транзакции
- **Экспорт в iCalendar (ICS)**: выгрузка задач с датами для импорта в Google Calendar, Apple Calendar, Outlook
- **Синхронизация с iCalendar**: автоматическая публикация задач в календарь
- **Редактирование в таблицах**: поддержка CSV позволяет править задачи в Excel / Google Sheets перед обратным импортом

### Настройки
- Тёмная и светлая тема
- Настраиваемый размер шрифта
- Кастомное название для задач без контекста
- Полная очистка базы данных с подтверждением

| Категория | Технология |
| --- | --- |
| **Язык** | Kotlin 2.0+ |

## Резервное копирование

### Экспорт

Настройки → **Экспорт в CSV** → выберите место сохранения

Будет создан файл со всеми данными:
- Контексты (названия, цвета, порядок)
- Задачи (иерархия, описания, приоритеты, даты, таймеры)
- Сессии таймера (время, длительность, комментарии)

### Импорт

Настройки → **Импорт из CSV** → выберите файл бэкапа

> **Важно**: при импорте текущие данные будут полностью заменены данными из файла. Убедитесь, что выбрали правильный файл.

### Удаление всех данных

Настройки → **Удалить ВСЁ** → подтвердите действие

> **Важно**: это действие необратимо! Перед удалением сделайте экспорт.

## Структура проекта

    app/src/main/java/com/example/voodoo/
    ├── MainActivity.kt              # Точка входа
    ├── VooDooApp.kt                 # Application класс
    ├── data/
    │   ├── AppDatabase.kt           # Room Database + миграции
    │   ├── Entities.kt              # Сущности БД
    │   ├── Dao.kt                   # DAO интерфейсы
    │   └── CsvHelper.kt             # Экспорт/импорт CSV
    ├── presentation/
    │   ├── MainViewModel.kt         # Главный ViewModel
    │   ├── CalendarViewModel.kt     # ViewModel календаря
    │   ├── TaskListViewModel.kt     # ViewModel списка задач
    │   ├── TaskDetailViewModel.kt   # ViewModel деталей задачи
    │   ├── ContextListViewModel.kt  # ViewModel контекстов
    │   ├── components/              # Переиспользуемые UI-компоненты
    │   └── screens/                 # Экраны приложения
    └── service/
        ├── CSVManager.kt            # Альтернативный менеджер CSV
        ├── ICalPublisher.kt         # Публикация в iCalendar
        ├── TimerServiceManager.kt   # Управление таймером
        ├── ReminderScheduler.kt     # Планировщик напоминаний
        └── ReminderReceiver.kt      # Получатель напоминаний
