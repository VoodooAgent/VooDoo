# 📋 VooDoo

Простое приложение-трекер задач для Android с возможностью объединения задач в проекты.

## Функции

- Создание проектов
- Добавление задач в проекты
- Отметка задач как выполненных
- Удаление задач и проектов
- Переименование проектов и задач
- Дополнительное описание к задачам
- Локальное хранение данных (Room)
- Поддержка тёмной темы (автоматически по системным настройкам)

## Технологии

- Kotlin
- Jetpack Compose
- Room Database
- Navigation Compose

## Установка

1. Клонируйте репозиторий
2. Откройте проект в Android Studio
3. Дождитесь синхронизации Gradle
4. Запустите приложение
