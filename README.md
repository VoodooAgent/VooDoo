# 📋 VooDoo

Мощное и лаконичное приложение-трекер задач для Android, построенное на принципах иерархичности и контекстного планирования. VooDoo позволяет объединять задачи в многоуровневые деревья, группировать их по смысловым категориям и фокусироваться на главном без визуального шума.

## 🌟 Основные возможности

### 🎨 Контексты
- **Смысловая группировка**: разделяйте задачи по проектам, сферам жизни или локациям
- **Визуальная персонализация**: 30 ярких цветов на выбор
- **100% окрашивание экрана**: цвет контекста полностью окрашивает фон и шапку экрана
- **Умный авто-контраст**: текст и иконки автоматически становятся белыми на тёмных цветах и чёрными на светлых
- **Гибкое управление**: создание, редактирование и удаление через меню настроек
- **Задачи без контекста**: поддерживается общий список задач вне привязки к проектам

### 🌳 Иерархия и Дерево задач
- **Глубокая вложенность**: поддержка деревьев задач до **7 уровней**
- **Визуальные связи**: вертикальные линии-направляющие чётко показывают принадлежность подзадач
- **Независимые статусы**: выполнение родителя не скрывает активные подзадачи — они остаются в рабочем списке
- **Автораскрытие родителя**: при создании подзадачи родитель автоматически разворачивается
- **Массовое управление**: одной кнопкой свернуть или развернуть все ветки на экране

### ✅ Работа с задачами
- **Компактные карточки**: оптимизированный UI для большого количества задач без лишнего скролла
- **Свайп-жесты**:
   - *Свайп вправо* — быстрое выполнение или возврат в активные
   - *Свайп влево* — контекстное меню (добавить подзадачу, редактировать, удалить и др.)
- **Приоритеты**: 4 уровня важности (0–3 звезды) с быстрой сменой по тапу
- **Встроенный таймер**: трекер времени с сохранением истории сессий
- **Планирование**: дата и время начала/конца + системные напоминания
- **Редактируемое название**: изменение прямо в карточке задачи
- **Защита от циклов**: нельзя выбрать родителем себя или своего потомка
- **Смена контекста с потомками**: при переносе задачи все её подзадачи тоже меняют контекст

### 📥 Архив выполненных задач
- **Разделение пространств**: активные задачи всегда сверху, выполненные — внизу
- **Секция «Выполнено»** по умолчанию свёрнута, чтобы не создавать визуальный шум
- **Умная группировка по времени** (календарная, без дублей):
   - 🟢 **Сегодня** — всегда раскрыто при открытии секции
   - 🗓 **За неделю** — текущая неделя (с понедельника)
   - 📅 **За месяц** — текущий календарный месяц
   - 📆 **За год** — текущий календарный год
   - 📚 **За всё время** — задачи старше текущего года
- **Сортировка**: внутри каждой группы — свежие сверху
- **Лёгкий возврат**: любая выполненная задача возвращается в активные одним нажатием

### ⭐ Экран «Приоритетные задачи»
- **Единый центр фокуса**: собирает важные задачи из всех контекстов
- **Группировка по контекстам** с реальными именами
- **Массовое сворачивание**: кнопка в заголовке сворачивает/разворачивает все секции сразу
- **Чистота списка**: выполненные задачи автоматически покидают экран
- **Пустое состояние**: понятное сообщение, если активных приоритетных задач нет

### 📱 Интерфейс и UX
- **Бесшовный дизайн**: чёрный статус-бар и навигационная панель для единого визуального стиля
- **Тёмная и светлая темы**: полная поддержка системных настроек
- **Локальное хранение**: надёжная база данных Room — ваши данные всегда под рукой и не требуют интернета
- **Меню настроек**: быстрый доступ по тапу на логотип "VooDoo" в левом верхнем углу

## 🛠 Технологии

| Категория | Технология |
|-----------|------------|
| **Язык** | Kotlin |
| **UI** | Jetpack Compose, Material Design 3 |
| **Архитектура** | MVVM + StateFlow |
| **База данных** | Room Database |
| **Навигация** | Navigation Compose |
| **Асинхронность** | Kotlin Coroutines & Flow |
| **Фоновая работа** | AlarmManager (напоминания), Foreground Service (таймер) |

## 🚀 Установка и запуск

### Требования
- Android Studio Ladybug (2024.2.1) или новее
- JDK 17+
- Android SDK 26+ (minSdk)
- Kotlin 2.0+

### Шаги
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/VoodooAgent/VooDoo.git
   ```
2. Откройте проект в Android Studio
3. Дождитесь окончания синхронизации Gradle и индексации файлов
4. Запустите приложение на эмуляторе или подключённом устройстве (`Shift+F10` или ▶️)
