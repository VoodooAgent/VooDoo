# 📋 VooDoo

Простое приложение-трекер задач для Android с возможностью объединения задач в проекты и группировки их по контекстам.

## Функции

### 🎨 Контексты
- **Группировка проектов**: объединяйте проекты по смысловым категориям (Контекстам).
- **Персонализация**: задавайте уникальное название и цвет фона для каждого контекста.
- **Цветные экраны**: каждый контекст имеет свой собственный экран с выбранным цветом фона, где отображаются только его проекты.
- **Управление**: создание, редактирование и удаление контекстов через специальный экран настроек.
- **Быстрый доступ**: экран настроек открывается по нажатию на стилизованный символ **"VD"** в левом верхнем углу приложения.

### 📁 Проекты
- Создание, редактирование и удаление проектов
- Привязка проектов к определенному контексту (или работа без контекста)
- Отображение первой невыполненной задачи под названием проекта
- Сортировка проектов: **вручную**, **по алфавиту**, **по дате создания**
- Режим ручного перемещения проектов (стрелки ↑↓)

### ✅ Задачи
- Добавление, редактирование и удаление задач
- Поле «Дополнительная информация» (описание задачи)
- Отметка задач как выполненных
- **Зачёркивание** выполненных задач + приглушение цвета
- Сортировка задач: **вручную**, **по алфавиту**, **по дате создания**
- Режим ручного перемещения задач (стрелки ↑↓)

### 📱 Интерфейс
- Компактное отображение списков (минимум отступов)
- Поддержка тёмной темы (автоматически по системным настройкам)
- Локальное хранение данных (Room) с автоматической миграцией базы данных

## Технологии

- Kotlin
- Jetpack Compose
- Material Design 3
- Room Database
- Navigation Compose
- Kotlin Coroutines & Flow
